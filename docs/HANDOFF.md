# Idee.Shop

Aplicație pentru organizarea ideilor, task-urilor, programărilor și rezultatelor financiare. Vezi README.md pentru pornire și documentația din docs pentru configurare.

Acest repository public conține un instantaneu al codului pentru portofoliu. Pentru o instalare nouă, pornește cu o bază proprie și configurează separat contul de administrator, Google Calendar și Hermes dacă ai nevoie de ele.
