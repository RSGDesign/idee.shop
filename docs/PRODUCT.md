# Produs
## Problemă și public
Ideile se pierd în liste separate, iar efortul și banii investiți nu sunt vizibili. Prima persoană utilizatoare este proprietarul proiectului; pe termen lung publicul larg care dezvoltă proiecte personale.
## MVP
Captură rapidă a ideilor; detalii cu descriere, stadiu, potențial estimat; frigider cu idei fixate; task-uri bifabile; note; registru de venituri și cheltuieli; obiectiv de venit în RON și progres; totaluri; backup export/import; căutare.
Flux: adaugă idee → descrie → definește un pas → notează bani → compară venitul cu obiectivul → validează sau arhivează.
## Criterii de acceptare
O idee și elementele ei persistă după refresh. Un task poate fi bifat. O cheltuială reduce profitul. Progresul folosește venitul, nu profitul. Frigiderul afișează doar ideile fixate. Importul invalid nu înlocuiește datele. Datele nu sunt trimise la un server extern.
## Excluderi
Autentificare, colaborare, plăți, marketplace, AI, fiscalitate, aplicație desktop nativă, sincronizare. Este o aplicație web locală folosită pe Mac.
