# Roadmap
1. MVP personal local (acum): organizare și evidență financiară simplă.
2. Stabilizare: teste browser, accesibilitate, componente separate, conflicte între taburi, UX mai bun pentru frigider.
3. Stocare durabilă locală: SQLite, migrare, backup automat controlat, eventual ambalare desktop.
4. Public larg numai cu acord: conturi, izolare date, sincronizare, securitate și găzduire aleasă explicit.
5. Marketplace: descoperire, dovezi de profit, licențiere și transfer, plăți, moderare, comisioane. Nu este activ în MVP.
Fiecare etapă se decide după folosirea celei precedente. Nu există termene sau promisiuni de profit.
