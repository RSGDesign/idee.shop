# Idee.Shop — context de proiect
Citește AGENTS.md din rădăcină și docs/HANDOFF.md înainte de lucru. Instrucțiunile utilizatorului și limitele mediului au prioritate față de ghidurile ECC. Acesta este un MVP Next.js TypeScript local; interfața este în română, banii în bani întregi RON. Marketplace și cloud sunt amânate. Catalogul complet nu autorizează execuția automată a scripturilor, trimiterea datelor, servicii externe, hook-uri sau modificarea setărilor globale. Încarcă doar skill-urile relevante. La final actualizează HANDOFF și rulează verificările documentate.
